# 🚀 EliézerDev - Landing Page

Uma landing page desenvolvida para apresentar meus projetos, compartilhar recursos e conectar pessoas interessadas em programação.

---

## ✨ Funcionalidades

- 🎯 Apresentação pessoal
- 💻 Seção de projetos
- 📖 Frase inspiradora
- 🤝 Convite para comunidade no Discord
- 📱 Layout responsivo (em desenvolvimento)
- ⚡ Interface simples e moderna

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (em breve)

## 🎯 Objetivo

Este projeto faz parte dos meus estudos de desenvolvimento web através do **The Odin Project**.

Meu objetivo foi praticar:

- Estruturação com HTML
- Flexbox
- Organização de layout
- Tipografia
- Cores
- Componentização da interface
